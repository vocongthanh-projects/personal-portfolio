# Thanh Vo — Personal Portfolio

A static, recruiter-first engineering portfolio presenting two complementary disciplines: QA automation and authorized penetration testing.

Production: [vocongthanh.com](https://vocongthanh.com)

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run check
```

The production site is statically exported to `out/` and can be hosted on GitHub Pages or any static hosting service.

## Content

Verified profile, project, capability, and practice data live in `src/data/portfolio.ts`. Private engagement names, endpoints, credentials, payloads, and unverified outcome metrics are intentionally excluded.
